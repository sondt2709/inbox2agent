# UI principles of the dashboard

The dashboard (`i2a`, `i2a config`) is the primary way for the user to change the configuration. Treat it like the admin UI of a web app.

1. The user can change each configuration item in the dashboard.
2. Put the configuration in the dashboard, as a typical admin UI does.
3. A UI control is mandatory. A shortcut key is optional.
4. The arrow keys move to each component.
5. The user can click each component.
6. Follow the common practice of a typical dashboard UI as much as possible. For example, a dialog has a save button and a close button.
7. A shortcut key and a key action do the same thing in all of the dashboard.
